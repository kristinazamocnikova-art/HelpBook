# HelpBook

A school-friendly homework assistant frontend.

## Run it
Open `index.html` in a browser. No build tools are required.

## Included
- Chat-style homework interface
- Explain / Solve / Study / Quiz Me / Check My Work modes
- Recent conversations saved in the browser
- Projects saved in the browser
- Responsive design for desktop and mobile
- No external websites are required by the demo

## Important deployment note
This version is a functional frontend/demo. Its answers are generated by simple built-in demo logic, not a real AI model.

For a real AI assistant, connect the chat request to an AI service through a school-approved backend. Keep API keys on the server, apply school content/safety rules, and follow the school's network and acceptable-use policies. The site is not intended to bypass school network restrictions.
